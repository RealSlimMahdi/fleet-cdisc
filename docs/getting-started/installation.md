# Installation

## Requirements

- Python 3.12+
- [uv](https://github.com/astral-sh/uv) (recommended) or pip

## Install

=== "uv (recommended)"

    ```bash
    uv add fleet-cdisc
    ```

=== "pip"

    ```bash
    pip install fleet-cdisc
    ```

### Optional extras

| Extra  | Installs         | When to use                    |
| ------ | ---------------- | ------------------------------ |
| `io`   | `pyreadstat`     | Reading SAS XPT (`.xpt`) files |
| `all`  | All extras       | Full feature set               |
| `docs` | MkDocs + plugins | Building this documentation    |
| `dev`  | pytest, ruff, io | Contributing to Fleet          |

```bash
# SAS XPT support
uv add "fleet-cdisc[io]"

# Development
uv add "fleet-cdisc[dev]"
```

## Verify the installation

```python
import fleet
print(fleet.__version__)  # e.g. 0.1.0
```

After the import the `.sdtm`, `.adam`, `.adsl`, and `.occds` namespaces are available on every `polars.DataFrame`.

# Quickstart

## 1. SDTM domain from raw data

```python
import fleet
import polars as pl
from codelists import SEX  # generated by: fleet init ct

raw = pl.DataFrame({
    "patient_id": ["001", "002", "003"],
    "sex_raw":    ["M", "F", "M"],
    "birth_date": ["1970-04-15", "1985-11-02", "1960-07-30"],
})

dm = (
    raw.sdtm
    .hardcode_no_ct("DOMAIN",  value="DM")
    .hardcode_no_ct("STUDYID", value="MYSTUDY01")
    .assign_no_ct("USUBJID",   source="patient_id")
    .assign_ct("SEX", source="sex_raw",
               ct_codelist=SEX, ct_mapping={"M": "M", "F": "F"})
    .assign_dtc("BRTHDTC", source="birth_date")
    .to_frame()
)
```

## 2. ADaM BDS dataset

```python
vs_sdtm = pl.DataFrame({
    "USUBJID":  ["001-01", "001-01", "001-01"],
    "VISITNUM": [1,         2,         3       ],
    "PARAMCD":  ["SYSBP",  "SYSBP",  "SYSBP" ],
    "AVAL":     [120.0,    115.0,    118.0   ],
    "ADT":      ["2024-01-10", "2024-02-10", "2024-03-10"],
    "TRTSDT":   ["2024-01-10", "2024-01-10", "2024-01-10"],
})

advs = (
    vs_sdtm.adam
    .source("USUBJID")
    .source("PARAMCD")
    .source("AVAL")
    .study_day("ADY", analysis_date="ADT", reference_date="TRTSDT")
    .flag("ABLFL", criteria='pl.col("VISITNUM") == 1',
          groups=["USUBJID", "PARAMCD"])
    .baseline("BASE", aval="AVAL", baseline_flag="ABLFL")
    .chg("CHG",  aval="AVAL", base="BASE")
    .pchg("PCHG", aval="AVAL", base="BASE")
    .to_frame()
)
```

## 3. ADSL (one row per subject)

```python
adsl = (

    .count_events("NUMAE", from_dataset=ae_sdtm)

```

## 4. define.yaml-driven pipeline

Fleet can read a `define.yaml` specification and execute the whole pipeline
without hand-writing verbs:

```python
from fleet import load_study_context

ctx = load_study_context("specs/cdiscpilot01/adam/define.yaml")
adsl = ctx.build("ADSL")   # reads inputs, applies derivations, validates output
```

See [How define.yaml works](../concepts/define-yaml.md) for the full spec format.

## 5. Generate Define-XML

```python
from fleet import DefineXMLGenerator

gen = DefineXMLGenerator("specs/cdiscpilot01/adam/define.yaml")
gen.write("outputs/cdiscpilot01/define_adam.xml")
```
