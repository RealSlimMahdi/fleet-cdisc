Expressions and contexts

The four places a Polars expression can run, and what Fleet does in each.

Polars 1.41.0 Fleet src/fleet/core/_verb_mixin.py Print two sides

DefinitionThe two words

Expression
A lazy description of a data transformation. A Python object. It holds no data and computes nothing. pl.col("AVAL") - pl.col("BASE") is an expression.
Context
The place an expression is run. The same expression gives a different result in a different context.

Source. Both definitions are from the Polars user guide, Expressions and contexts.

TableThe four contexts

ContextResult shapeRuleClosest SAS
df.select(...) Only the columns you name All results must share one length, or be a scalar that broadcasts PROC SQL select list
df.with_columns(...) All original columns, plus the new ones Results must match the original row count DATA step assignment
df.filter(...) Same columns, fewer rows Expressions must evaluate to Boolean WHERE or subsetting IF
df.group_by(...).agg(...) One row per group Grouping columns first, then one column per aggregate PROC SUMMARY
The one that is not a context

.over(...) is not a context. It is a modifier on an expression. It computes per group but gives back one row per input row, not one row per group. This is the SAS PROC SQL remerge, where a summary statistic is joined back onto the detail rows.

AnatomyHow an expression is built

Every step returns a new expression. Nothing runs. The object is only a plan until a context receives it.

StartersWhere an expression begins

pl.col

pl.col("AVAL")
pl.col("AVAL", "BASE")
pl.col(pl.Float64)

Name one column, several columns, or every column of a dtype. The last two expand into several expressions.

pl.lit

pl.lit("Y")
pl.lit(None, dtype=pl.String)

A constant. Needed when the value is not a column. Give a dtype for a typed null.

pl.when

pl.when(cond).then(a)
  .when(cond2).then(b)
  .otherwise(c)

Branching. Chain several .when() calls for an if / else if ladder. First match wins.

pl.len

pl.len()

Row count. Useful inside .agg() and .over().

Mental model for a SAS programmer

A Fleet verb chain is not a series of DATA steps. It is one DATA step that you are still writing. to_frame() is the run;.

TrapsThings that will catch you

Null is not NaN

Missing data is always null, for every dtype. NaN is a valid float, not missing. Aggregations such as mean and sum skip null but propagate NaN. null_count() does not count NaN. See Missing data.

and / or / not do not work

Use &, |, ~, and parenthesise every operand: (a > 1) & (b < 2). Python's and tries to reduce an expression to a single true or false value, which an expression is not.

group_by is not over

group_by collapses to one row per group. over keeps every row. If a Fleet verb returns fewer rows than you expected, this is the first thing to check. See Window functions.

select needs equal lengths

In select, every expression must produce the same length, or a scalar that broadcasts. Mixing a 5-row column and a 2-row column raises an error.

InspectSeeing an expression without running it

root_names() and output_name() are exactly what Fleet's _validate_chain_exprs uses to tell you that a column is missing before anything is collected.
