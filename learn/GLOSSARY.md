# Polars (in the context of Fleet) Glossary

The canonical language for this teaching workspace. Lessons, drills, and learning
records must use these terms.

A term is added here only after understanding of it has been demonstrated, not after
it has been taught. The glossary is a record of compressed knowledge, not a
dictionary to read.
