    CLI Reference¶

    Fleet ships the fleet command-line tool (version 0.1.0) for bootstrapping studies, executing derivation pipelines, validating datasets, generating Define-XML, managing CDISC Controlled Terminology, and rendering TLGs. Commands that query the CDISC Library require a valid CDISC_API_KEY — set it in a .env file at your project root or as an environment variable.

    .env
    CDISC_API_KEY=your-api-key-here

    Conventions¶

    • Config discovery — every command that needs study_config.yaml finds it git-style: the current directory first, then each parent. Pass --config <path> to override.
    • Exit codes — 0 success, 1 on a Fleet error (a single clean message on stderr), 2 on a usage error (missing/unknown command or flag).
    • Errors go to stderr; results go to stdout.
    • fleet --version prints the installed version.

    Run fleet <command> --help for the authoritative, always-current usage.

    Command inventory¶

    Command What it does
    fleet init Bootstrapping pipeline: cfg → define → ct → rules.
    fleet run Execute define.yaml derivation pipelines and write datasets.
    fleet validate Validate datasets with the CDISC Rules Engine (exit 1 on errors).
    fleet check CI gate: config parse + define.yaml schema + custom-rule YAMLs.
    fleet new Bootstrap a study: init cfg → define → ct → rules, one confirmation.
    fleet migrate Rewrite removed pre-alpha verb/kwarg spellings to canonical ones (libcst).
    fleet tdd Trial design workflow: build/audit TDD datasets from trial_design.yaml.
    fleet tlg TLG workflow: list templates, run/explore YAML specs, export summaries.
    fleet define-xml Generate Define-XML 2.1 from a define.yaml specification.
    fleet add-acrf Declare the annotated CRF document (study.documents block) in define.yaml.
    fleet add-ct Add domains to an existing codelists.py (preserves existing).
    fleet add-rule Scaffold a new custom validation rule YAML.
    fleet check-rule Validate a custom rule YAML (syntax, structure, schema).
    fleet install-engine Download the CDISC Rules Engine binary for validation.
    fleet uninstall-engine Remove the managed CDISC Rules Engine binary.
    fleet doctor Check Fleet setup: engine, API key, optional extras.
    fleet derivation Scaffold and manage study-specific derivations.
    fleet mcp Serve Fleet tools to MCP-capable assistants (requires the 'mcp' extra).
    fleet lsp Language server for define.yaml files (requires the 'lsp' extra).

    fleet init¶

    fleet init cfg¶

    Option Default Description
    --study-id (required) Study identifier (e.g. CDISCPILOT01).
    --company (none) Originator / company name.
    --domains (none) Comma-separated SDTM domains (e.g. DM,AE,VS,EX).
    --adam-datasets (none) Comma-separated ADaM datasets (e.g. ADSL,ADVS,ADAE).
    --ig 3-4 SDTM IG version (default: 3-4).
    --adam-ig 1-1 ADaM IG version (default: 1-1).
    --package sdtmct-2023-12-15 CT package version (default: sdtmct-2023-12-15).
    --root / -r . Study root directory (default: current directory).

    fleet init define¶

    Option Default Description
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
    --sdtm-only (none) Generate SDTM define.yaml only (skip ADaM).
    --adam-only (none) Generate ADaM define.yaml only (skip SDTM).
    --force (none) Overwrite existing define.yaml files.

    fleet init ct¶

    Option Default Description
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
    --no-docs (none) Omit definitions and preferred terms from generated code.
    --force (none) Overwrite existing codelists.py.

    fleet init rules¶

    Option Default Description
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
    --sdtm-only (none) Fetch SDTM rules only (skip ADaM).
    --adam-only (none) Fetch ADaM rules only (skip SDTM).
    --force (none) Overwrite existing rule files.

    fleet run¶

    Option Default Description
    --dataset (none) Dataset to build (repeatable). Default: every dataset in the define files.
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
    --out / --output / -o (none) Output directory for every dataset. Default: the configured data/sdtm and data/adam directories.
    --format parquet Output format (default: parquet). Choices: parquet, xpt, dataset-json.
    --strict / --no-strict (on) Raise on unknown spec algorithms (default). --no-strict warns and skips.

    fleet validate¶

    Argument Description
    paths Dataset files or directories (parquet / csv / xpt / sas7bdat). Default: the configured sdtm_data and adam_data directories.
    Option Default Description
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
    --standard (none) Force the standard. Default: AD* datasets → adam, others → sdtm. Choices: sdtm, adam.
    --version (none) IG version. Default: the sdtm/adam ig_version declared in the discovered study_config.yaml (3.4 / 1.3 outside a study).
    --custom-rules (none) Directory of custom validation rule YAML files. Default: validation.custom_rules from the discovered study_config.yaml.
    --report (none) Write an HTML findings report to PATH.

    fleet check¶

    Option Default Description
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).

    fleet new¶

    Argument Description
    study_id Study identifier (e.g. STUDY01).
    Option Default Description
    --domains (none) Comma-separated SDTM domains (e.g. DM,AE,VS,EX).
    --adam-datasets (none) Comma-separated ADaM datasets (e.g. ADSL,ADVS,ADAE).
    --company (none) Originator / company name.
    --ig 3-4 SDTM IG version (default: 3-4).
    --adam-ig 1-1 ADaM IG version (default: 1-1).

    fleet tlg¶

    fleet tlg list¶

    fleet tlg schema¶

    Argument Description
    template_id Registry template id (e.g. aet01). See fleet tlg list.

    fleet tlg run¶

    Argument Description
    spec A spec .yaml file or a directory of spec files.
    Option Default Description
    --data (none) Analysis dataset path, repeatable. Plain PATH applies to every spec; NAME=PATH (e.g. ADAE=adae.parquet) targets the template's analysis domain.
    --adsl (none) ADSL dataset path (population denominators for tables).
    --output / -o (none) Output directory. Default: the configured outputs directory (current directory outside a study workspace).
    --format html Output format (default: html). Choices: html, rtf, pdf, pptx.
    --groupby (none) Treatment-arm column. Default: auto-detect (TRTA → TRT01A → TRT01P).
    --title "" Output title (default: template title).
    --subtitle "" Output subtitle.
    --footnote (none) Footnote (repeatable).
    --rows-per-page (none) Maximum body rows per page (model-layer pagination).
    --page-by (none) ARD variable to page-break on (e.g. PARAMCD).
    --watch (none) Re-run whenever a spec file changes (requires the 'watch' extra).

    fleet tlg explore¶

    Argument Description
    spec A spec .yaml file or a directory of spec files.
    Option Default Description
    --data (none) Analysis dataset path, repeatable. Plain PATH applies to every spec; NAME=PATH (e.g. ADAE=adae.parquet) targets the template's analysis domain.
    --adsl (none) ADSL dataset path (population denominators for tables).
    --output / -o (none) Output HTML file. Default: explorer.html in the configured outputs directory (current directory outside a study workspace).
    --groupby (none) Treatment-arm column for specs without a groupby axis. Default: auto-detect (TRTA → TRT01A → TRT01P).
    --title "" Output title (default: template title).
    --subtitle "" Output subtitle.
    --footnote (none) Footnote (repeatable).
    --watch (none) Rebuild whenever a spec file changes (requires the 'watch' extra).

    fleet tlg export¶

    Option Default Description
    --domain (required) TLG sub-namespace to summarise. Choices: ae, cm, dm, ds, eg, ex, lb, mh, vs.
    --format html Output format (default: html). Choices: html, rtf, pdf, pptx.
    --data (none) Path to the primary analysis dataset. Default: the analysis dataset the domain's t_summary template declares (e.g. ADAE for ae, ADSL for dm/ds), found in the configured data directories.
    --adsl (none) Path to the ADSL dataset. Default: ADSL found in the configured adam_data directory.
    --output / -o (none) Output file path. Default: _summary. in the configured outputs directory (current directory outside a study).
    --groupby (none) Treatment-arm column. Default: auto-detect (TRTA → TRT01A → TRT01P).
    --title "" Table title.
    --subtitle "" Table subtitle.
    --footnote (none) Footnote (repeatable).
    --rows-per-page (none) Maximum body rows per page (model-layer pagination).
    --page-by (none) ARD variable to page-break on (e.g. PARAMCD).
    --wrap (none) Path to an HTML wrapper template with {table} placeholder.

    fleet define-xml¶

    Option Default Description
    --spec / -s (none) Path to the define.yaml specification file. Default: /define.yaml from the discovered study_config.yaml (per --standard).
    --output / -o (none) Output path for the Define-XML file. Default: /define_.xml from the discovered study_config.yaml.
    --standard sdtm Which define.yaml to use for the config-based defaults (default: sdtm). Choices: sdtm, adam.
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
    --no-preview (none) Skip generating the HTML preview alongside the XML.
    --enrich-methods (none) Embed Python verb / callable docstrings into Define-XML Origin descriptions and emit MethodDef elements with FormalExpression. Creates a verifiable link between the regulatory submission and the exact code that produced the data.
    --watch (none) Re-generate whenever the spec file changes (requires the 'watch' extra).

    fleet add-acrf¶

    Option Default Description
    --href blankcrf.pdf aCRF file path in the submission package (default: blankcrf.pdf).
    --title (none) Display title (default: "Annotated Case Report Form").
    --page-map (none) External DOMAIN.VARIABLE → pages YAML file, relative to define.yaml.
    --standard sdtm Which define.yaml to update (default: sdtm). Choices: sdtm, adam, both.
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).

    fleet add-ct¶

    Option Default Description
    --domains (required) Comma-separated SDTM domain abbreviations to add.
    --ig (none) SDTM IG version. Default: sdtm.ig_version from the discovered study_config.yaml (3-4 outside a study).
    --package (none) CT package version. Default: ct.package from the discovered study_config.yaml (sdtmct-2023-12-15 outside a study).
    --output / -o (none) Path to the existing codelists.py. Default: /codelists.py from the discovered study_config.yaml (./codelists.py outside a study).
    --no-docs (none) Omit definitions and preferred terms from generated code.

    fleet add-rule¶

    Option Default Description
    --domain (required) SDTM/ADaM domain code (e.g. AE, DM, VS).
    --description (required) Human-readable description of the rule.
    --prefix FLEET Rule ID prefix (default: FLEET).
    --id (none) Explicit rule ID (e.g. ROCHE-AE-042). Skips auto-increment.
    --output / -o (none) Output directory for the rule YAML. Defaults to validation.custom_rules from study_config.yaml.
    --config / -c (none) Path to study_config.yaml. Default: discovered by walking up from the current directory (git-style).
